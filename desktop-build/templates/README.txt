Gold Exchange - Desktop (Offline)
=================================

INSTALL (customer)
  1. Extract this ZIP to any folder (e.g. Desktop\GoldExchange)
  2. Double-click "Start Gold Exchange.bat"
  3. Register your company on first use, then log in
  4. When finished, run "Stop Gold Exchange.bat"

REQUIREMENTS
  - Windows 10 or 11 (64-bit)
  - No XAMPP or internet required for daily use
  - Set your thermal receipt printer as Windows DEFAULT printer
  - Receipts print automatically (no preview dialog)
  - Do not delete the "data" folder (your database lives there)

BACKUP
  - Use Settings > Backup inside the app
  - Or copy the entire "data" folder to a safe location

TROUBLESHOOTING
  - "Port 3307 in use" -> close other MySQL/MariaDB or restart PC
  - "Port 8080 in use" -> close other Gold Exchange instance
  - White/blank page -> wait 10 seconds and run Start again
