🧪 Purchase Page - Row Click Functionality Test

📋 Test Instructions

Step 1: Open Purchase Page

Navigate to: http://localhost/Mormukut/purchase.php

Make sure you're logged in to the system.

Step 2: Check Recent Purchases Table

Look at the "Recent Purchases" section on the right side of the page.

✅ Expected: You should see a list of recent purchase transactions with columns:
  • ID & Date
  • Party
  • Weight & Type
  • Amount
  • Actions (Eye icon for view, Trash icon for delete)
⚠️ If table is empty: Create at least one purchase transaction first by filling out the form on the left.
Step 3: Test Row Click (Edit Functionality)

Click anywhere on a purchase row (NOT on the action buttons).

✅ Expected Behavior:
  • The form on the left should populate with the transaction data
  • Purchase ID label should show (Editing) in orange
  • Submit button should change to orange and say "Update Purchase"
  • Form border should turn orange (2px solid)
  • Page should scroll to the form
Step 4: Test View/Print (Eye Icon)

Click the blue eye icon in the Actions column.

✅ Expected: A modal should appear showing the purchase receipt with options to:
  • Send WhatsApp
  • Print
  • OK (close)
Step 5: Test Delete (Trash Icon)

Click the red trash icon in the Actions column.

✅ Expected: A confirmation dialog should appear showing:
  • Receipt ID
  • Weight
  • Amount
  • Warning: "This action cannot be undone!"

If you confirm, the transaction should be deleted and the page should reload.

🔍 Troubleshooting

Open Browser Console

Press F12 or Ctrl+Shift+I to open Developer Tools, then go to the Console tab.

Look for any error messages (shown in red).

Check for JavaScript Errors

Common errors to look for:

  • $ is not defined - jQuery not loaded
  • Swal is not defined - SweetAlert2 not loaded
  • loadPurchaseForEdit is not a function - Function not defined
Verify Data Attributes

Right-click on a purchase row and select "Inspect Element".

Check if the <tr> element has these attributes:

  • class="... selectable-row ..."
  • data-transaction-id="[number]"
  • data-receipt-id="[P...]"
  • data-transaction="[base64 string]"

🐛 If Nothing Happens When Clicking Rows

Possible Causes:
  1. No transactions in database: Create a purchase first
  2. JavaScript not loaded: Check browser console for errors
  3. Event handler not attached: Refresh the page (Ctrl+F5)
  4. Data attributes missing: Check the HTML source
Quick Fix: Hard Refresh

Press Ctrl+Shift+R (or Ctrl+F5) to clear cache and reload the page.
